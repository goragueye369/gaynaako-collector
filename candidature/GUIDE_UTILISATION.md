# 👤 Guide Utilisateur - Candidature Préremplie

**Version**: 1.0  
**Public**: Utilisateurs finaux (Entrepreneurs, PME, ONG)

---

## 🎯 Qu'est-ce que la Candidature Préremplie ?

Gaynaako utilise **intelligemment** les informations de votre profil pour **préremplir automatiquement** les formulaires de candidature aux opportunités.

### ✅ Avantages

- **Gain de temps** : Plus besoin de ressaisir vos informations à chaque candidature
- **Zéro erreur** : Pas de risque de typo ou d'oubli
- **Suivi centralisé** : Tous vos dossiers au même endroit
- **Transparence totale** : Vous voyez exactement ce qui manque
- **Amélioration continue** : Votre profil s'enrichit automatiquement

---

## 🚀 Comment Ça Marche ?

### Étape 1 : Sélectionner une Opportunité

1. Parcourez les opportunités dans l'onglet **"🏆 Recommandations"**
2. Cliquez sur une opportunité qui vous intéresse
3. Cliquez sur **"📄 Préparer ma candidature"**

### Étape 2 : Vérifier Votre Dossier

Gaynaako analyse automatiquement votre profil et vous montre :

#### ✅ Informations Disponibles

```
✅ Nom complet: Fatou Sow
✅ Adresse email: fatou.sow@gaynaako.sn
✅ Téléphone: +221 77 123 45 67
✅ Pays: Sénégal
✅ Expertise: Intelligence Artificielle, Machine Learning
✅ Formation: Master 2 en IA
✅ Expérience: 5 ans
✅ CV: https://storage.gaynaako.sn/cv/fatou_sow.pdf
```

#### ❌ Informations Manquantes

Si des informations obligatoires manquent, Gaynaako vous le dit clairement :

```
❌ Information manquante : numéro de téléphone
   → Veuillez renseigner votre numéro de téléphone

❌ Information manquante : années d'expérience  
   → Veuillez indiquer vos années d'expérience professionnelle
```

### Étape 3 : Compléter les Informations Manquantes

1. Remplissez **uniquement** les champs qui manquent
2. Cliquez sur **"💾 Enregistrer"**
3. ✅ Ces informations sont **automatiquement sauvegardées** dans votre profil
4. Vous n'aurez plus à les ressaisir pour vos prochaines candidatures !

### Étape 4 : Générer Votre Lettre de Motivation (Optionnel)

Une fois votre dossier complet (100%), vous pouvez :

1. Cliquer sur **"✨ Générer la lettre de motivation"**
2. L'IA de Gaynaako rédige une lettre **adaptée à l'opportunité**
3. La lettre utilise **uniquement vos vraies compétences** (pas d'invention !)
4. Vous pouvez la **modifier** si nécessaire
5. Cliquer sur **"📋 Copier la lettre"** pour l'utiliser

### Étape 5 : Soumettre Votre Candidature

1. Vérifiez que tout est correct
2. Cliquez sur **"🚀 Soumettre ma candidature"**
3. ✅ Votre dossier est marqué comme "SOUMIS"
4. Vous pouvez le retrouver dans **"Mes candidatures"**

## 📊 Score de Complétude

Chaque dossier a un **score de complétude** :

| Score | Statut | Action |
|-------|--------|--------|
| **100%** | ✅ Complet | Prêt à soumettre |
| **80-99%** | ⚠️ Presque complet | Compléter 1-2 champs |
| **50-79%** | 🟡 Incomplet | Plusieurs champs manquants |
| **< 50%** | 🔴 Très incomplet | Profil à enrichir |

## 🛡️ Principe de Non-Invention

### ❌ Ce que Gaynaako NE FAIT PAS

Gaynaako **N'INVENTE JAMAIS** de données pour vous :

```
❌ Inventer un numéro de téléphone
❌ Inventer une expérience professionnelle
❌ Inventer un diplôme
❌ Inventer des compétences
❌ Inventer un CV
```

### ✅ Ce que Gaynaako FAIT

Gaynaako est **honnête et transparent** :

```
✅ Identifie précisément ce qui manque
✅ Vous demande de compléter
✅ Enregistre vos vraies informations
✅ Réutilise ces informations pour vos prochaines candidatures
✅ Génère des lettres basées sur vos vraies compétences
```

## 💡 Conseils Pratiques

### 1. Enrichissez Votre Profil Progressivement

À chaque candidature, vous complétez quelques informations. Rapidement, votre profil sera complet et vous n'aurez plus rien à remplir !

### 2. Vérifiez Vos Informations

Prenez le temps de relire vos informations avant de soumettre. Gaynaako les remplit automatiquement, mais vous restez maître de vos données.

### 3. Personnalisez Votre Lettre

Si Gaynaako génère une lettre de motivation, **personnalisez-la** ! Ajoutez des détails spécifiques à l'opportunité.

### 4. Suivez Vos Candidatures

Utilisez l'onglet **"📄 Mes Candidatures"** pour suivre toutes vos candidatures :

- 🟢 **Soumises** : Candidatures envoyées
- 🟡 **Complètes** : Prêtes à envoyer
- 🔴 **Brouillons** : En cours de préparation

## 🔍 FAQ

### Q: Mes données sont-elles sécurisées ?

**R**: Oui, toutes vos données sont stockées de manière sécurisée dans la base de données Gaynaako. Elles ne sont jamais partagées avec des tiers.

### Q: Puis-je modifier mes informations ?

**R**: Oui, vous pouvez modifier votre profil à tout moment dans **"Mon Profil"**.

### Q: Gaynaako invente-t-il des données pour compléter mon profil ?

**R**: **Non, jamais !** C'est notre principe fondamental. Si une information manque, nous vous demandons explicitement de la fournir.

### Q: La lettre de motivation est-elle toujours parfaite ?

**R**: La lettre générée par IA est un **excellent point de départ**, mais nous recommandons de la **personnaliser** selon l'opportunité.

### Q: Combien de candidatures puis-je créer ?

**R**: Autant que vous voulez ! Il n'y a aucune limite.

### Q: Puis-je supprimer une candidature ?

**R**: Oui, vous pouvez supprimer les candidatures en brouillon. Les candidatures soumises sont archivées pour votre historique.

### Q: Que se passe-t-il si je complète une information manquante ?

**R**: L'information est **automatiquement enregistrée** dans votre profil. Vous n'aurez plus à la ressaisir pour vos prochaines candidatures.
